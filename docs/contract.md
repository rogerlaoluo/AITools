# contract.md

实现一个完整的续签评估系统，该评估系统严格安装提供的评分标准进行评估


## 1、业务规则

### 1.1、职级和年龄
- 18级以下:职级 * 2 >= 年龄。完全满足条件得100分，职级x2小于年龄时，每小一年扣20分
- 19级及以上: 年龄门槛放宽至44~45岁
- 职级范围为13~22
- 该因素占续签结果30%

### 1.2、绩效评估
- 绩效以A/B+为主，续签率大幅度提升
- 常年B+也可能因为业务调整面临风险
- A:100分；B+:80分；B:60分； C/D:0分
- 可评估2022~2025年的年度绩效
- 各年份的平均值作为该因素的最终得分
- 该因素占续签结果40%

### 1.3、所在团队业务发展潜力
- 发展空间非常大: 100分
- 发展空间较大: 80分
- 发展空间非一般: 60分
- 发展空间非差: 40分
- 该因素占续签结果20%

### 1.4、其它因素
- 其它因素1: 金牌个人/团队等荣誉为续签加分
- 其它因素2: 核心项目经验和技术专长是优势
- 其它因素3: 团队协作能力也是重要考量
- 其它因素加起来占续签结果10%


## 2、续签规则
- 总分 = (职级和年龄得分 * 0.3) + (绩效评估 * 0.4) + (所在团队业务发展潜力 * 0.2) + (其它因素 * 0.1)
- 总分 >= 90: 一定续签
- 70 <= 总分 < 90: 大概率续签
- 60 <= 总分 < 90: 可能续签
- 总分 < 60： 不续签
