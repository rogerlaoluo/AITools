# Part 2: 商业模式深度解析

### 2024年定价变革（MQB模式）

**MQB = Maximum Quantity Billing（最大用量计费）**

| 变更点 | 影响 |
|--------|------|
| **计费方式** | 从月均用户数 → 月度峰值用户数 |
| **涨价幅度** | Jira Service Management: +7-20% |
|  | Jira Software/Confluence: 结构性调整 |
|  | Opsgenie: +5-10% |
| **批量折扣** | 用户越多，单价越低（渐进式折扣）|

**策略意图：**
- 推动客户从Server/Data Center迁移到Cloud
- 提升ARPU（每用户平均收入）
- 锁定大客户长期订阅

### 2024年重大技术升级：数据库迁移

**Atlassian成功迁移400万个数据库至AWS Aurora**

| 指标 | 迁移前 | 迁移后 |
|------|--------|--------|
| **数据库数量** | 分散的PostgreSQL实例 | 统一的Aurora集群 |
| **运营成本** | 基准 | **降低50%** |
| **可靠性** | 标准SLA | **提升99.99%** |
| **扩展性** | 手动维护 | 自动弹性 |

**技术意义：**
- 支撑Jira Cloud快速扩张
- 降低基础设施成本
- 提升服务稳定性
